How to Add Registry Keys to Favorites in Regedit

Navigating the Windows Registry Editor (Regedit) can be time-consuming when managing deeply nested key paths. This guide provides a straightforward method for administrators to bookmark frequently accessed registry keys using the built-in Favorites feature, streamlining administrative workflows and preventing navigation errors.

Adding a Registry Key to Favorites

To bookmark a key path in the Windows Registry Editor, follow these steps:

  1. Open Registry Editor: Press Win + R, type regedit, and press Enter. If prompted by User Account Control (UAC), click Yes to run with administrative privileges.
  2. Navigate to the Target Key: Use the left-hand navigation tree to locate the specific registry key you want to save. Click on the key folder to highlight it.
  3. Open the Favorites Menu: Click on Favorites in the top menu bar.
  4. Select Add to Favorites: Click Add to Favorites... from the drop-down menu.
  5. Name the Favorite: In the dialog box that appears, type a descriptive name for the shortcut to help identify it later.
  6. Save: Click OK to save the path to your list.

Accessing Saved Registry Favorites

Once saved, accessing your bookmarked keys takes only two clicks:

  1. Open Regedit.
  2. Click Favorites on the menu bar.
  3. Select your saved favorite from the bottom of the list. Regedit will immediately expand the tree and highlight the target key.

Removing or Managing Favorites

If a registry path is no longer needed, you can delete it from your favorites list:

  1. Open Regedit and click Favorites on the top menu bar.
  2. Select Remove Favorite....
  3. Highlight the name of the favorite you wish to delete.
  4. Click OK to confirm removal.
