Change Windows Lock Screen Timeout in Regedit

By default, Windows turns off the monitor after just one minute of inactivity when the computer is on the lock screen. This article explains which Windows Registry value unlocks the hidden "Console lock display off timeout" setting, enabling you to adjust how long your screen stays on before turning off on the lock screen.

The Registry Key and Value

To manage the lock screen display timeout, you must modify the Attributes DWORD value inside the Power Settings key.

  • Registry Path: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power\PowerSettings\7516b95f-f776-4464-8c53-06167f40cc99\8EC4B3A5-6868-48c2-BE75-4F3044BE88A7
  • Value Name: Attributes
  • Type: REG_DWORD
  • Default Value Data: 1 (Setting is hidden)
  • New Value Data: 2 (Setting is visible)

Step-by-Step Instructions

  1. Press Windows Key + R, type regedit, and press Enter to open the Registry Editor.

  2. Navigate to the following path:

    HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power\PowerSettings\7516b95f-f776-4464-8c53-06167f40cc99\8EC4B3A5-6868-48c2-BE75-4F3044BE88A7

  3. Double-click the Attributes DWORD entry in the right pane.

  4. Change the Value data from 1 to 2, then click OK.

  5. Close the Registry Editor.

Adjusting the Lock Screen Timeout

Once the registry value is set to 2, the setting becomes available in your advanced power options:

  1. Press Windows Key + R, type control powercfg.cpl, and press Enter.
  2. Click Change plan settings next to your active power plan.
  3. Click Change advanced power settings.
  4. Scroll down and expand the Display category.
  5. Expand the newly visible option named Console lock display off timeout.
  6. Enter your preferred timeout duration in minutes (e.g., 5, 10, or 15).
  7. Click Apply, then click OK to save the changes.
